{% load i18n %} {% comment %} SCM global search. Included by the SCM shell (scm/base.html), so it is on every SCM page rather than on any one of them. The backend is `analytics:search` over `search_scm` — one search implementation, team-scoped in the selector. This is only the way in. ⌘K / Ctrl-K focuses the field. Deliberately small: a shortcut, not a command palette. It only steals the key combination while an SCM page is open, and Escape closes the panel and returns the keyboard to the page. Alpine owns the panel's open state and HTMX owns its contents. The results partial keeps the `#scm-search-results` id in every state, including the empty one, so a cleared query cannot leave stale results on screen. {% endcomment %}
