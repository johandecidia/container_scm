{% extends "scm/base.html" %} {% load i18n %} {% comment %} Provider account status — plan, allowance, billing cycle. Reached only through `tracking:provider_status`, which is superuser-only. Everything on this page describes the installation's own agreement with a provider, not any team's data. It is a separate page rather than a card hidden on a shared one on purpose: the server must never send these numbers to a team administrator, so there is no team-facing template that could ever render them. The tracking layer does not persist them either — see `carriers/exceptions.py` on `safe_message` — so the only copy outside this page is the application log. `used` and `active` are shown as the two different numbers they are, and the page says so, because the obvious misreading is expensive: untracking lowers `active` and leaves `used` where it is, so treating `active` as the spend would claim capacity the account does not have. {% endcomment %} {% block app %}
