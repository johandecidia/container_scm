A location was previously reachable only as a container list filtered to it; this is the page that answers the questions a place actually raises — what is here, what is expected, what has moved. Four tabs, one page load, in the same Alpine shell as the Container and Purchase Order workspaces: panels in the DOM, `?tab=` for a bookmarkable tab, no router. Inventory is the exception to "everything in the DOM": it filters and paginates server-side over the shared container list, because a depot holding six hundred boxes should not render six hundred rows to let somebody search them.
