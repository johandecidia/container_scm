{% extends "scm/base.html" %} {% load i18n %} {% load django_vite %} {% comment %} The Container Workspace, served by the long-standing `containers:detail` route so every existing link, bookmark and redirect keeps working. Four sections, one page load. The tabs are Alpine state over markup that is all present in the DOM: switching costs no request, nothing can be lost by a swap, and the tracking refresh reaches both the Overview summary and the Journey timeline in one response. All four panels being present is also why the map works. There is one map per page — map.js takes the single `[data-scm-map]` element — and it fits its bounds once its GeoJSON arrives. A map that started hidden would fit those bounds to a zero-height canvas, so the map lives on Overview, which is the tab that is open on arrival. `?tab=` makes a tab bookmarkable. It is read once on load and written with replaceState on switch: no router, no history entries to back out of. This is the reference implementation for the Shipment, Purchase Order and Location workspaces that follow, so the tab shell and the header are written to be copied. {% endcomment %} {% block app %} {% include "scm/containers/partials/container_workspace_header.html" %}
