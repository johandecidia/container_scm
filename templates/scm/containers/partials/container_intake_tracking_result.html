{% load i18n %} {% comment %} What automatic tracking did for the containers an import just created. Renders nothing when tracking was not asked for, and nothing when it was asked for but there were no new containers — an import of numbers that all already existed has no tracking outcome to report, and a line saying "0 started" would read as a failure. A container that could not be tracked is named. The import succeeded and its containers exist; what did not happen is the tracking, and the only way that is recoverable is if somebody can see which boxes it was. The reasons are the lifecycle's own messages, built from outcome values rather than from provider error text, so nothing here can leak a response body or a credential.
