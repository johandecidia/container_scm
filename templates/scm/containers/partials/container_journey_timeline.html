{% load i18n %} {% comment %} One timeline for the whole journey, whoever reported each part of it: every carrier that has tracked this box, and our own physical observations. Each row names its source, so two sources describing the same leg read as two accounts of one journey rather than as a contradiction. Lives on the workspace Journey tab. A tracking refresh targets the Overview summary, so this element is re-rendered out of band in the same response (`oob=True`) — one request, one carrier call, both tabs current. Every row shows only what its source actually said, in a fixed order — what happened, where, on what. Absent fields collapse rather than render as blanks or dashes, so the shape of a row says how much is known about it. An event we could not classify still shows the carrier's own wording and codes: a gap in our mapping tables must cost the reader detail, not the whole event. A point that has coordinates carries data-map-event-id, which is the whole contract between the timeline and the map: clicking the row flies the map to that point, and selecting it on the map highlights the row. The timeline stays the authoritative chronology — the map only points at it, and cannot show a place we have no coordinates for. {% endcomment %}
