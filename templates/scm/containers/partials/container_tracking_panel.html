{% load i18n %} {% comment %} Carrier tracking for one container — an HTMX component with a stable root id. Refresh posts to containers:refresh_tracking and swaps this whole element, so the summary, the result banner and the timeline can never disagree with each other. Everything shown is derived from the container's shipment, its tracking subscription and its tracking events. None of it is stored on Container. The carrier we would ask and the carrier that actually tracks the box are two different things and are shown as such: a subscription exists only where a carrier has returned data, so "Maersk ● Active" is never shown for a carrier that was merely tried. A shipment booked with Maersk that Maersk has no events for yet reads as an untracked container with a shipment carrier — which is what it is. A container can have several verified sources at once — carriers that covered different legs, plus our own physical record — so they are listed, every timeline entry says which one reported it, and a segment none of them explains is called out rather than smoothed over. {% endcomment %}

{% comment %} One timeline for the whole journey, whoever reported each part of it: every carrier that has tracked this box, and our own physical observations. Each row names its source, so two sources describing the same leg read as two accounts of one journey rather than as a contradiction. Every row shows only what its source actually said, in a fixed order — what happened, where, on what. Absent fields collapse rather than render as blanks or dashes, so the shape of a row says how much is known about it. An event we could not classify still shows the carrier's own wording and codes: a gap in our mapping tables must cost the reader detail, not the whole event. A point that has coordinates carries data-map-event-id, which is the whole contract between the timeline and the map: clicking the row flies the map to that point, and selecting it on the map highlights the row. The timeline stays the authoritative chronology — the map only points at it, and cannot show a place we have no coordinates for. {% endcomment %}
