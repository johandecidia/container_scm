{% load i18n %} {% comment %} Carrier tracking for one container — an HTMX component with a stable root id. Refresh posts to containers:refresh_tracking and swaps this whole element, so the summary, the result banner and the timeline can never disagree with each other. Everything shown is derived from the container's shipment, its tracking subscription and its tracking events. None of it is stored on Container. The carrier we would ask and the carrier that actually tracks the box are two different things and are shown as such: a subscription exists only where a carrier has returned data, so "Maersk ● Active" is never shown for a carrier that was merely tried. A shipment booked with Maersk that Maersk has no events for yet reads as an untracked container with a shipment carrier — which is what it is. {% endcomment %}
