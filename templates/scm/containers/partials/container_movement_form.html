{% load i18n %} {% comment %} Record a physical movement: gate in, gate out, receive, transfer. One modal for all four. Changing the movement type re-labels the two location fields and shows only the ends that movement has — Alpine, because it is pure presentation. It is not validation: the server decides what a movement needs, and a form posted with JavaScript off is checked exactly as strictly. The time field is deliberately the physical time, not the entry time, and says so. Movement precedence is decided on when the box moved, so a gate-in typed up an hour late must carry the hour it happened or it will outrank things it should not. On success the response asks HTMX to reload the page. A movement changes the header, the physical state panel and the Activity tab together, and swapping one of them would leave the other two describing the container as it was. {% endcomment %}
