{% load i18n %} {% comment %} The tracking state of one container: who is watching it, what they last said, where it is, when it arrives and how current that is. Lives on the workspace Overview as the answer to "what is the state of this box right now". The root id is the HTMX target: `containers:refresh_tracking` swaps this element outerHTML and re-renders the journey timeline out of band, so the summary, the result banner and the timeline can never disagree with each other. Everything shown is derived from the container's shipment, its tracking subscriptions and its tracking events. None of it is stored on Container. The carrier we would ask and the carrier that actually tracks the box are two different things and are shown as such: a subscription exists only where a carrier has returned data, so "Maersk ● Active" is never shown for a carrier that was merely tried. A shipment booked with Maersk that Maersk has no events for yet reads as an untracked container with a shipment carrier — which is what it is. A container can have several verified sources at once — carriers that covered different legs, plus our own physical record — so they are listed here and every timeline entry says which one reported it. {% endcomment %}
