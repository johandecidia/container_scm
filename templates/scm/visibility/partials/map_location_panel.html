{% load i18n %} {% comment %} What one map marker expands into: the containers of one position class standing at — or heading for — one canonical location. Rendered by Django rather than assembled in JavaScript, so it uses the same components as the rest of SCM and every carrier-supplied string is escaped by the template engine. The heading states the kind of claim before it states the place. "84 containers at Oceanterminalen" and "84 containers bound for Oceanterminalen" are two very different sentences, and a panel that opened with the place name would leave the reader to guess which one they were looking at. Every row leads to the Container Workspace. That is where a container is understood and acted on; this panel is a way into it, not a second detail page. {% endcomment %}
