{% load i18n %} {% comment %} The coverage summary: how complete the location data is, in two rows of numbers. The container numbers are LOC-4's own — `quality.coverage` is the `MapCoverage` the Control Tower's map is drawn from — so this page and that map cannot disagree about how much of the fleet is plottable. "Plottable" is defined once, in map_positions, and read here. The evidence numbers count events that name a place, which is the same set the two queues below aggregate. An event that happened nowhere — a bill of lading issued — is not evidence about a location and is not counted as unresolved. {% endcomment %}
