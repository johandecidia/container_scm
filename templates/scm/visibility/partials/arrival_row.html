Usage: {% include "scm/visibility/partials/arrival_row.html" with object=object %} Same reflowing grid as the exceptions queue — dense from `sm` up, stacked below — and the same single link per row, to the object's own page. Destination is the canonical location where the shipment has one, and the booked destination text otherwise — `destination_label` decides, so this template holds no rule about which. A canonical destination also gets a marker, because "bound for the place we call Oceanterminalen" and "bound for somewhere a carrier spelled Gothenburg" are different degrees of certainty and the row should not flatten them. Where there is no shipment there is no destination, and the row says so rather than printing where the box is now: current location is not a destination. {% endcomment %}
