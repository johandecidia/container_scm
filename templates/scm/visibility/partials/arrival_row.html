{% load i18n %} {% comment %} One expected arrival: a shipment with its boxes, or a container tracked on its own. Usage: {% include "scm/visibility/partials/arrival_row.html" with object=object %} Same reflowing grid as the exceptions queue — dense from `sm` up, stacked below — and the same single link per row, to the object's own page. Destination is the canonical location where the shipment has one, and the booked destination text otherwise — `destination_label` decides, so this template holds no rule about which. A canonical destination also gets a marker, because "bound for the place we call Oceanterminalen" and "bound for somewhere a carrier spelled Gothenburg" are different degrees of certainty and the row should not flatten them. Where there is no shipment there is no destination, and the row says so rather than printing where the box is now: current location is not a destination. Since LOC-3 the row also carries where this is in the inbound process. Two badges, because they answer different questions: the lifecycle state says whether the box is here, and health says whether the journey is in trouble. A row that showed only one of them would leave the other unanswerable from the queue. A row that has arrival evidence prints the movement it rests on — "Gate In 5 Sep 14:32" — rather than only a state, so the queue can be interrogated without opening the container. {% endcomment %}
