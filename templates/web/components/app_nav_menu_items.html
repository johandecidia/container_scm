{% load i18n %} {% comment %} Primary navigation for Container SCM. Grouped by the work a supply chain user does, not by Django app: Control, Supply Chain, Network, Insights. Pegasus owns the shell — the team selector above this list, the account and admin groups below it — and this file only decides what the SCM experience puts inside it. Control is a drill-down, not three views of the same thing: the Control Tower is the summary, and Exceptions and Arrivals are the work queues it leads into. They were filter links onto the Control Tower until the queues existed; the old filtered URLs still work, but they are no longer where the navigation points. Tracking, Discovery, Imports, Integrations, Supplier Deliveries and AI Chat are deliberately absent from the primary groups. Every one of those routes still works; the technical capabilities are reached from the objects they belong to, and the administrative ones from Settings below. {% endcomment %}
